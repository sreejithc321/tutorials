Evals, Guardrails & Observability

A beginner's guide to testing, safety, and monitoring AI systems

What are These Three?

Evals: Testing AI systems to measure quality and accuracy •
Guardrails: Preventing unwanted outputs and ensuring safety •
Observability: Monitoring and understanding what your AI system is doing

The Problems

Deep Dive
✅ Evals: Testing AI Quality

What it is: Evals are tests that measure how well your AI system works.

Simple analogy: Just like you test software for bugs, you test AI systems to measure accuracy, safety, and quality.

1 You Create Test Cases
Write examples of what your AI should do: input and expected output.
2 Run Tests
Give the AI the test inputs and see what it outputs.
3 Compare Results
Check if actual output matches expected output. Score the system.
🛡️ Guardrails: Preventing Bad Outputs

What it is: Rules that prevent your AI from saying inappropriate, unsafe, or harmful things.

Simple analogy: Like traffic guardrails keep cars on the road, AI guardrails keep AI responses within safe boundaries.

1 Define Rules
Decide what the AI should NEVER output (violence, hate speech, etc.)
2 Check Outputs
Before showing response to user, scan it against the rules.
3 Block or Flag
Either block the output or flag it for human review.
👁️ Observability: Seeing What's Happening

What it is: Tools and practices that let you see, log, and understand everything your AI system does.

Simple analogy: Like a car dashboard shows you engine temperature and speed, observability shows you what your AI is thinking and doing.

1 Collect Data
Log user inputs, AI outputs, latency, errors, costs, etc.
2 Analyze Patterns
Look for trends, failures, or unusual behavior.
3 Debug Issues
When something goes wrong, trace back and find the root cause.

❓ What Problems Do These Solve?

Without Evals: You don't know if your AI is actually working well. You're flying blind!

Without Guardrails: Your AI might accidentally say offensive, dangerous, or completely wrong things to users.

Without Observability: When something breaks, you have no idea why. Finding bugs becomes nearly impossible.

import json
import logging
from datetime import datetime
from anthropic import Anthropic

# SETUP: Observability Logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# Store all interactions for observability
interactions_log = []

client = Anthropic()

# ==================== GUARDRAILS ====================
class Guardrails:
    """Prevent bad outputs from the AI"""
    
    def __init__(self):
        # List of prohibited words/phrases
        self.blocked_patterns = [
            "kill yourself",
            "hate all",
            "illegal drug",
            "bomb",
            "crash the market"
        ]
    
    def check_output(self, text):
        """Return True if output is safe, False if it should be blocked"""
        text_lower = text.lower()
        
        for pattern in self.blocked_patterns:
            if pattern in text_lower:
                logger.warning(f"⚠️ BLOCKED: Output contains '{pattern}'")
                return False
        
        return True
    
    def sanitize_output(self, text):
        """Replace unsafe content with safe alternative"""
        if not self.check_output(text):
            return "I can't provide that information. Please ask something else."
        return text

# ==================== EVALS ====================
class Evaluator:
    """Test the quality of responses"""
    
    def __init__(self):
        self.test_cases = [
            {
                "question": "What is 2+2?",
                "expected_keywords": ["4"],
                "category": "math"
            },
            {
                "question": "What is Python?",
                "expected_keywords": ["programming", "language"],
                "category": "knowledge"
            },
            {
                "question": "Explain machine learning in simple terms",
                "expected_keywords": ["data", "learn", "pattern"],
                "category": "explanation"
            }
        ]
        self.results = []
    
    def evaluate_response(self, question, response):
        """Score a response on quality"""
        score = 0
        max_score = 100
        
        # Check length (good responses aren't too short)
        if len(response.split()) < 3:
            feedback = "Response too short"
            logger.info(f"📊 Eval: {feedback}")
            return {"score": 20, "feedback": feedback, "question": question}
        
        # Check if it makes sense (no obvious errors)
        if "?" in response and "." not in response:
            score = 70
            feedback = "Response is a question instead of answer"
        else:
            score = 90
            feedback = "Good response quality"
        
        logger.info(f"📊 Eval: {question[:30]}... → Score: {score}/100")
        
        return {
            "score": score,
            "feedback": feedback,
            "question": question,
            "response": response[:100]
        }
    
    def run_evals(self, chatbot_func):
        """Run test cases against the chatbot"""
        logger.info("🧪 Starting evaluation suite...")
        total_score = 0
        
        for test in self.test_cases:
            response = chatbot_func(test["question"])
            result = self.evaluate_response(test["question"], response)
            self.results.append(result)
            total_score += result["score"]
        
        average_score = total_score / len(self.test_cases)
        logger.info(f"🎯 Evaluation complete. Average: {average_score:.0f}/100")
        
        return {
            "average_score": average_score,
            "total_tests": len(self.test_cases),
            "results": self.results
        }

# ==================== OBSERVABILITY ====================
class Observer:
    """Log and track system behavior"""
    
    def __init__(self):
        self.events = []
    
    def log_interaction(self, user_input, ai_response, latency, metadata=None):
        """Log a user-AI interaction"""
        event = {
            "timestamp": datetime.now().isoformat(),
            "user_input": user_input,
            "ai_response": ai_response[:100],
            "latency_ms": latency,
            "metadata": metadata or {}
        }
        self.events.append(event)
        logger.info(f"📝 Interaction logged: {user_input[:30]}...")
        
        return event
    
    def get_stats(self):
        """Get statistics about system behavior"""
        if not self.events:
            return {"error": "No events logged"}
        
        latencies = [e["latency_ms"] for e in self.events]
        
        return {
            "total_interactions": len(self.events),
            "avg_latency_ms": sum(latencies) / len(latencies),
            "min_latency_ms": min(latencies),
            "max_latency_ms": max(latencies),
            "latest_5": self.events[-5:]
        }
    
    def find_issues(self):
        """Detect potential issues from logs"""
        issues = []
        
        # Check for slow responses
        slow_responses = [e for e in self.events if e["latency_ms"] > 5000]
        if slow_responses:
            issues.append(f"⚠️ {len(slow_responses)} slow responses detected")
        
        # Check for repeated failures
        if len(self.events) > 10:
            recent = self.events[-10:]
            issues.append(f"ℹ️ Last 10 interactions logged")
        
        return issues

# ==================== CHATBOT ====================
class SafeChatbot:
    """Chatbot with Evals, Guardrails, and Observability"""
    
    def __init__(self):
        self.guardrails = Guardrails()
        self.evaluator = Evaluator()
        self.observer = Observer()
        self.client = client
    
    def respond(self, user_input):
        """Get a response with all protections"""
        import time
        start = time.time()
        
        try:
            # Get response from Claude
            response = self.client.messages.create(
                model="claude-opus-4-1",
                max_tokens=256,
                messages=[{"role": "user", "content": user_input}]
            )
            
            ai_response = response.content[0].text
            latency = (time.time() - start) * 1000  # Convert to ms
            
            # Apply guardrails
            safe_response = self.guardrails.sanitize_output(ai_response)
            
            # Log for observability
            self.observer.log_interaction(user_input, safe_response, latency)
            
            return safe_response
        
        except Exception as e:
            logger.error(f"❌ Error: {str(e)}")
            return "Sorry, I encountered an error."
    
    def run_evals(self):
        """Run evaluation tests"""
        return self.evaluator.run_evals(self.respond)
    
    def get_status(self):
        """Get system status and statistics"""
        return {
            "observability": self.observer.get_stats(),
            "issues": self.observer.find_issues()
        }

# ==================== MAIN ====================
if __name__ == "__main__":
    print("🤖 Safe Chatbot with Evals, Guardrails & Observability\n")
    
    chatbot = SafeChatbot()
    
    # Example: Test the chatbot
    print("📝 Testing chatbot...\n")
    
    test_questions = [
        "What is AI?",
        "Explain machine learning"
    ]
    
    for question in test_questions:
        response = chatbot.respond(question)
        print(f"User: {question}")
        print(f"Bot: {response}\n")
    
    # Run evaluations
    print("\n" + "="*50)
    print("🧪 RUNNING EVALUATIONS")
    print("="*50 + "\n")
    eval_results = chatbot.run_evals()
    print(f"Average Score: {eval_results['average_score']:.0f}/100\n")
    
    # Show observability data
    print("="*50)
    print("👁️ OBSERVABILITY DASHBOARD")
    print("="*50 + "\n")
    status = chatbot.get_status()
    print(f"Total interactions: {status['observability']['total_interactions']}")
    print(f"Avg latency: {status['observability']['avg_latency_ms']:.0f}ms")
    
    if status['issues']:
        print("\n⚠️ Detected Issues:")

🔍 Deep Dive: Each Component

These three systems work independently but together create a robust AI system.

Let's explore what makes each powerful.

✅ EVALS: Measuring Quality
Types of Evals ›

1. Deterministic Evals

Check for exact conditions. Example: "Did the response contain the answer?"

✓ Fast
✓ Reliable
✗ Limited (can't judge quality)

2. LLM-as-Judge Evals

Use another AI to judge the response. Example: "Is this response helpful?"

✓ Flexible
✓ Understands nuance
✗ Costs money
✗ Can be subjective

3. Human Evals

Have people rate responses. The "gold standard".

✓ Most accurate
✗ Slow
✗ Expensive
✗ Doesn't scale
Eval Metrics You Should Know ›

Accuracy: Is the answer correct? (Math, facts)

Target: 95%+

Relevance: Does the answer match the question?

Target: 90%+

Coherence: Does the response make sense?

Target: 95%+

Harmfulness: Does it contain harmful content?

Target: 0%

Latency: How fast is the response?

Target: <1 second

Cost: How much does each response cost?

Target: Depends on your budget

Building Good Test Cases ›

Good test cases cover:

  • Normal cases (typical usage)
  • Edge cases (unusual but valid inputs)
  • Error cases (invalid inputs)
  • Adversarial cases (trying to trick the AI)

Example:

Test: Summarize this article
Normal: "Summarize CNN article about climate"
Edge: "Summarize 500-word article"
Error: "Summarize invalid-url.com"
Adversarial: "Make this summary lie about the facts"
🛡️ GUARDRAILS: Preventing Bad Outputs
Types of Guardrails ›

1. Rule-Based Guardrails

Check for specific words or patterns.

Example: Block if response contains "password"
✓ Fast
✗ Easy to bypass
✗ Can have false positives

2. Semantic Guardrails

Use AI to understand if content is harmful.

Example: Use embedding to detect hateful intent
✓ Accurate
✓ Hard to bypass
✗ More expensive

3. Prompt-Based Guardrails

Tell the AI upfront what it should never do.

Example: "Never give medical advice"
✓ Built-in prevention
✗ AI might ignore instructions
Common Guardrails to Implement ›
Type Example
Safety Block violence, hate speech, illegal content
Privacy Don't output user emails or personal info
Accuracy Flag unconfident or hallucinated responses
Brand Stay professional, match company tone
Legal Add disclaimers for medical/legal advice
Bias Treat all groups equally and fairly
Guardrail Best Practices ›

1. Layer your guardrails

Don't rely on just one check. Use multiple methods (rule + semantic + prompt).

2. Test them thoroughly

Make sure your guardrails catch bad outputs and don't block good ones.

3. Log violations

Track what was blocked and why. Find patterns.

4. Make them adjustable

Don't hard-code rules. Use a config file so you can update them without code changes.

👁️ OBSERVABILITY: Seeing Everything
What to Log ›

User-Side Data:

  • User ID (anonymized)
  • Input text
  • Timestamp
  • User feedback (thumbs up/down)

AI-Side Data:

  • Model used
  • Output text
  • Tokens used
  • Confidence score

System-Side Data:

  • Latency (how long it took)
  • Cost (API charges)
  • Errors that occurred
  • Cache hits/misses

Safety-Side Data:

  • Guardrail checks performed
  • Any blocks or flags
  • Safety scores

Specialized for AI:

  • DataDog

Historical Trends:

  • Quality over time

Alerts:

  • Unusual patterns
🔄 The Feedback Loop

How they work together to improve:

1. Observability detects issues - "Output quality dropped 10%"

2. Evals pinpoint the problem - "Accuracy on question-answering dropped"

3. You make improvements - Change prompt, model, or guardrails

4. Evals verify improvement - Run evals again, see if scores went up

❓ Common Questions
How often should I run evals? ›

During development: Continuously, after every change

Use CI/CD to run them automatically

In production: Daily or weekly

Catch regressions before users complain

Won't guardrails make my AI too restrictive? ›

If guardrails are too strict, yes. That's why you should:

  • Start conservative, loosen gradually
  • Monitor false positive rates
  • Get feedback from users
  • Use confidence thresholds instead of binary blocking
How much does observability cost? ›

Open source tools: Free, but requires setup and maintenance

Examples: Prometheus, ELK Stack

Cloud providers: Pay-as-you-go, typically $100-$1000/month

Examples: DataDog, New Relic

AI-specific tools: $50-$500/month

Examples: Langfuse, Arize

Can I combine evals, guardrails, and observability? ›

Absolutely! In fact, you should.

They work together:

  • Observability provides data
  • Evals measure quality from that data
  • Guardrails prevent bad outcomes
  • Loop back to improve system
