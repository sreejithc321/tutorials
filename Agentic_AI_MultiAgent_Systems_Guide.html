Agentic AI & Multi-Agent Systems

A beginner's guide to autonomous agents and agent collaboration

What Are We Building?

Agentic AI: AI systems that can make decisions, take actions, and use tools autonomously
Multi-Agent Systems: Multiple agents working together, each with their own goals and abilities

🤖 What Is an Agent?

Simple definition: An AI system that can perceive its environment, make decisions, and take actions to achieve a goal.

Real analogy: Like a robot that can see, think, and act. It doesn't just respond to questions—it actively works toward goals.

⚙️ How Agents Work
Observe
→
Think
→
Act
→
Repeat
1 Observe
Agent sees the current state (user request, data, environment)
2 Think
Agent reasons about what to do. Uses its "brain" (AI model) and past knowledge.
3 Act
Agent uses tools to take action (call an API, write data, search the web)
4 Repeat
Agent observes the results and decides next steps. Loop continues until goal is reached.
👥 What Are Multi-Agent Systems?

Simple definition: Multiple agents working together, each with their own specialized skills and goals, to solve a larger problem.

Real analogy: Like a team of specialists. One writes, one edits, one designs, one publishes. Together they create better content than one person alone.

🔄 Agent vs Regular AI
Aspect Regular AI Agent AI
Control User gives command Agent decides what to do
Action Only responds with text Takes real actions (calls APIs, writes files)
Iteration One turn per request Multiple turns until goal met
Tools No access to tools Can use many tools
Planning No planning Makes step-by-step plans
Memory Single conversation Can learn and remember
🏗️ Agent Components

Brain (LLM)

The AI model that thinks and makes decisions. Usually a large language model like Claude.

Memory

What the agent remembers. Can be short-term (current conversation) or long-term (past experiences).

Tools

Things the agent can do. Examples: call APIs, search the web, write files, access databases.

Planning

How the agent breaks down goals into steps. "What do I need to do first, second, third?"

❓ What Problems Do Agents Solve?

Problem 1: Humans have to manage everything
Without agents, you have to tell AI what to do step-by-step. With agents, they figure it out themselves.

Problem 2: AI can only talk, not act
Regular AI just gives you suggestions. Agents can actually perform tasks and see results.

Problem 3: Complex tasks need specialists
A single person can't do research, write, edit, and design. A team can. Multi-agent systems work like teams.

Problem 4: Scaling human work
Agents can work 24/7 on repetitive tasks, freeing humans for creative work.

💡 Real-World Scenarios

Scenario 1: Research Paper Writer

Without agents: You manually: search papers, read them, extract info, write summary, check references

With agents: Agent autonomously searches, reads, synthesizes, and writes complete paper. You just review.

Scenario 2: Software Testing

Without agents: Testers manually click, type, verify each feature. Takes weeks.

With agents: Multiple test agents run in parallel, testing different scenarios. Completed in hours.

Scenario 3: Customer Issue Resolution

Without agents: Each issue needs a human to investigate, research, and solve.

With agents: Agent investigates, checks knowledge base, calls APIs, and resolves. Escalates only when needed.

🤝 Why Multi-Agent Systems?

Specialization: Each agent is expert at one thing. Researcher agent researches. Writer agent writes. Better results than a generalist.

Parallel Work: Multiple agents work at the same time. 3 agents working in parallel = 3x faster.

Redundancy: If one agent fails, others continue. More robust system.

Complexity: Break huge problems into smaller ones each agent can handle.

🚀 Simple Project: Multi-Agent Content Creator

We'll build a system where multiple agents collaborate to create a blog post: Research Agent finds information, Writer Agent writes, Editor Agent checks quality.

Project Goal

Build a 3-agent system where agents autonomously collaborate to create content. Each agent has tools, makes decisions, and passes work to the next agent.

2 Build Multi-Agent System

Create content_creation_agents.py:

from anthropic import Anthropic
import json

client = Anthropic()

# ==================== AGENT BASE CLASS ====================
class Agent:
    """Base class for all agents"""
    
    def __init__(self, name, role, tools):
        self.name = name
        self.role = role
        self.tools = tools
        self.conversation_history = []
    
    def think(self, task):
        """Agent thinks about what to do"""
        system_prompt = f"""You are {self.name}, a {self.role}.
        Your tools: {', '.join([t['name'] for t in self.tools])}
        
        Think step-by-step about what to do.
        Be autonomous - make decisions without asking for permission."""
        
        self.conversation_history.append({
            "role": "user",
            "content": task
        })
        
        response = client.messages.create(
            model="claude-opus-4-1",
            max_tokens=1024,
            system=system_prompt,
            messages=self.conversation_history
        )
        
        thought = response.content[0].text
        self.conversation_history.append({
            "role": "assistant",
            "content": thought
        })
        
        return thought
    
    def work(self, task):
        """Agent performs work on the task"""
        print(f"\\n{'='*50}")
        print(f"🤖 {self.name} ({self.role})")
        print(f"{'='*50}")
        
        result = self.think(task)
        print(f"\\n{result}")
        
        return result

# ==================== SPECIALIZED AGENTS ====================
class ResearchAgent(Agent):
    """Gathers information about a topic"""
    
    def __init__(self):
        tools = [
            {"name": "search_web", "description": "Search the internet for information"},
            {"name": "read_sources", "description": "Read articles and extract key points"}
        ]
        super().__init__(
            name="Research Agent",
            role="researcher who finds quality sources and extracts information",
            tools=tools
        )
    
    def research(self, topic):
        """Research a topic and return key findings"""
        print(f"\\n📚 Researching: {topic}")
        
        findings = {
            "topic": topic,
            "key_facts": [
                f"Fact 1 about {topic}: Important information",
                f"Fact 2 about {topic}: More details",
                f"Fact 3 about {topic}: Additional context"
            ],
            "sources": ["source1.com", "source2.com"],
            "summary": f"Research on {topic} completed with {3} key findings"
        }
        
        return self.work(f"Research this topic and find key information: {topic}")

class WriterAgent(Agent):
    """Writes the actual content"""
    
    def __init__(self):
        tools = [
            {"name": "write_content", "description": "Write high-quality content"},
            {"name": "format_markdown", "description": "Format content as markdown"}
        ]
        super().__init__(
            name="Writer Agent",
            role="professional writer who creates engaging content",
            tools=tools
        )
    
    def write(self, topic, research):
        """Write content based on research"""
        print(f"\\n✍️ Writing content about: {topic}")
        
        task = f"""Write a blog post about {topic}.
        Based on this research: {research[:200]}...
        
        Make it engaging, well-structured, and informative."""
        
        return self.work(task)

class EditorAgent(Agent):
    """Reviews and improves content"""
    
    def __init__(self):
        tools = [
            {"name": "check_grammar", "description": "Check grammar and spelling"},
            {"name": "improve_clarity", "description": "Improve writing clarity"}
        ]
        super().__init__(
            name="Editor Agent",
            role="professional editor who ensures high quality",
            tools=tools
        )
    
    def edit(self, content):
        """Review and improve content"""
        print(f"\\n📝 Editing content")
        
        task = f"""Review this content and suggest improvements:
        {content[:300]}...
        
        Check for:
        - Grammar and spelling
        - Clarity and flow
        - Structure and organization
        - Engagement level"""
        
        return self.work(task)

# ==================== AGENT COORDINATOR ====================
class AgentCoordinator:
    """Manages multiple agents and their collaboration"""
    
    def __init__(self):
        self.research_agent = ResearchAgent()
        self.writer_agent = WriterAgent()
        self.editor_agent = EditorAgent()
        self.workflow_log = []
    
    def create_content(self, topic):
        """Coordinate agents to create content"""
        print(f"\\n{'#'*60}")
        print(f"# CONTENT CREATION WORKFLOW FOR: {topic}")
        print(f"{'#'*60}")
        
        # Step 1: Research
        print("\\n📊 PHASE 1: RESEARCH")
        research = self.research_agent.research(topic)
        self.workflow_log.append({"phase": "research", "output": research[:100]})
        
        # Step 2: Write
        print("\\n📊 PHASE 2: WRITING")
        content = self.writer_agent.write(topic, research)
        self.workflow_log.append({"phase": "writing", "output": content[:100]})
        
        # Step 3: Edit
        print("\\n📊 PHASE 3: EDITING")
        final = self.editor_agent.edit(content)
        self.workflow_log.append({"phase": "editing", "output": final[:100]})
        
        # Summary
        print(f"\\n{'='*60}")
        print(f"✅ CONTENT CREATION COMPLETE")
        print(f"{'='*60}")
        print(f"Topic: {topic}")
        print(f"Agents involved: Research, Writer, Editor")
        print(f"Workflow phases: {len(self.workflow_log)}")
        
        return {
            "topic": topic,
            "workflow": self.workflow_log,
            "status": "completed"
        }

# ==================== MAIN ====================
if __name__ == "__main__":
    print("\\n🤖 Multi-Agent Content Creation System\\n")
    
    coordinator = AgentCoordinator()
    
    # Create content on a topic
    result = coordinator.create_content("Artificial Intelligence in Healthcare")
    
    print(f"\\n📊 FINAL RESULT: {json.dumps(result, indent=2)}")

🔍 Understanding Agent Architecture

An agent is a loop:

┌─────────────────────────────────┐ │ 1. Agent sees current state │ ├─────────────────────────────────┤ │ 2. Agent decides what to do │ ├─────────────────────────────────┤ │ 3. Agent acts (uses tools) │ ├─────────────────────────────────┤ │ 4. Agent observes result │ ├─────────────────────────────────┤ │ 5. Repeat until goal achieved │ └─────────────────────────────────┘

This loop repeats until the agent achieves its goal or runs out of attempts.

🧩 Core Patterns
Agentic Loop (ReAct Pattern) ›

ReAct = Reasoning + Acting

Agent alternates between thinking and acting.

Thought: "I need to find the current weather"
Action: Call weather API
Observation: "Temperature is 72°F"
Thought: "Good, now I can give the user the answer"
Action: Return answer to user
Planning (Chain-of-Thought) ›

Agents break goals into steps

Instead of jumping to action, agent plans first.

Goal: Write a research paper
Plan:
  1. Search for papers on topic
  2. Read and summarize key papers
  3. Identify gaps in research
  4. Write introduction
  5. Write methodology
  6. Write results
  7. Write conclusion
  8. Format and cite

Then executes each step in order.

Tool Use ›

Agents decide which tools to use

Like you would reach for a hammer or screwdriver depending on the job.

Available tools:
- search_web() - Search the internet
- read_file() - Read local files
- call_api() - Call external APIs
- write_file() - Save data

Agent: "I need to search for information"
Agent: uses search_web()

Agent: "Now I need to save this"
Agent: uses write_file()
Memory Types ›

Short-term memory: Current conversation context. Helps agent remember what's happening now.

Lasts: One session

Long-term memory: Past experiences and knowledge. Helps agent learn from what happened before.

Lasts: Across sessions, stored in database

Working memory: Current task context. What am I working on right now?

Lasts: Duration of current task

👥 Multi-Agent Patterns
Sequential Collaboration ›

Agents work one after another

Output of agent 1 → Input for agent 2 → etc.

Researcher writes report
         ↓
Editor improves it
         ↓
Designer adds visuals
         ↓
Publisher publishes it

Good for: Pipelines, workflows, assembly lines

Parallel Collaboration ›

Agents work at the same time

All start with same task, work independently, combine results.

Agent 1 → Analyzes data
Agent 2 → Finds patterns
Agent 3 → Checks quality
Agent 4 → Writes report
All work simultaneously!

Good for: Fast processing, independent subtasks

Hierarchical Collaboration ›

Agents organized in hierarchy

Manager agent delegates to worker agents.

Manager Agent (CEO)
    ├── Research Team Lead
    │   ├── Web Searcher Agent
    │   └── Paper Reader Agent
    ├── Writing Team Lead
    │   ├── Outline Agent
    │   └── Content Agent
    └── Quality Team Lead
        ├── Grammar Checker Agent
        └── Fact Checker Agent

Good for: Large teams, complex organization

🛠️ Building Effective Agents
Tool Design ›

Good tool design:

  • Clear name: "search_web" not "do_stuff"
  • Clear description: Agent understands what it does
  • Clear inputs/outputs: Agent knows what to pass
  • Clear errors: Agent knows when it fails

Bad tool:

def tool(x):
    # Do something
    return result

Good tool:

def search_web(query: str) -> dict:
    """Search the web for information.
    
    Args:
        query: What to search for
        
    Returns:
        dict with keys: results (list), count (int)
    """
    # Implementation
    return {"results": [...], "count": 3}
Prompt Engineering for Agents ›

Be specific about agent behavior:

You are a research agent. Your job is to:

2. Read and extract key information
3. Synthesize findings into insights
4. Report with citations

You have access to:
- search_web() - Search the internet
- read_url() - Read web pages

Think through each step carefully.
Check facts before reporting them.

Give examples:

Example 1:
Input: "What is quantum computing?"
You should: Search for information, read sources,
synthesize into clear explanation
Output: Detailed explanation with sources
Error Handling ›

Agents need to handle failures:

  • Tool fails (API down) - Retry or use alternative
  • Tool returns bad data - Validate and try again
  • Agent gets stuck - Set max attempts limit
  • Conflicting goals - Escalate to human

Pattern:

max_attempts = 3
current_attempt = 0

while current_attempt < max_attempts:
    try:
        result = agent.work()
        if result_is_good(result):
            return result
    except AgentError:
        current_attempt += 1
        
if current_attempt >= max_attempts:
    escalate_to_human()

⚠️ Challenges & Best Practices
Challenge: Agents Getting Stuck ›

Problem: Agent loops forever, taking same action repeatedly.

Solution: Set max iterations limit. Track what's been tried. Provide new information or tools.

Challenge: Hallucinations in Agents ›

Problem: Agent makes up facts instead of using tools.

Solution: Require agents to use tools for factual queries. Validate tool outputs. Use RAG for grounding.

Challenge: Cost Control ›

Problem: Agents make many API calls, costs add up fast.

Solution: Set budget limits. Cache tool results. Use cheaper models for simple tasks. Monitor costs closely.

Challenge: Agent Coordination ›

Problem: Multiple agents conflict or duplicate work.

Solution: Use coordinator agent. Assign clear roles. Use shared state to prevent duplication.

❓ Common Questions
How is an agent different from function calling? ›

Function calling: You decide which function to call. AI just picks which one.

Example: "Call search_web" or "call read_file"

Agent: AI decides what to do AND how many times. It loops until goal is reached.

Example: Agent autonomously searches, reads, analyzes, decides to search again

How many agents should I use? ›

Start with 1-2 agents. Add more as needed.

More agents = more complex, harder to debug. Keep it simple.

Sweet spot: 3-5 specialized agents working together.

Are agents safer than regular AI? ›

Not automatically. In fact, agents are riskier because they take actions.

A bad agent could delete files, spend money, or send wrong emails.

Solution: Careful guardrails on what agents can do. Human review for important actions.

Can I use the same agent for different tasks? ›

Yes, but not ideal. Generalist agents are less effective than specialists.

One agent doing research, writing, editing, and designing? Not great at any of them.

Better: Specialize agents. Research agent only researches. Writer agent only writes.
